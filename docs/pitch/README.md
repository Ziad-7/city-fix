# Pitch kit

Material for the SolveThe17 2.0 submission (Track 4, "Unlocking Egypt's Waste Economy"). Every claim points to a file or test; anything unmeasured says "to verify".

- [video-script.md](video-script.md): 3-minute demo video, shot by shot, with Arabic voice-over and English subtitles, plus a recording checklist
- [deck-outline.md](deck-outline.md): technical deck, one slide per section, each with the evidence in the repo
- [judges-qa.md](judges-qa.md): likely judge questions, grouped by what is simulated, tested or still to verify
- Source of truth for status: [../evidence.md](../evidence.md); diagram: [../architecture.md](../architecture.md)
